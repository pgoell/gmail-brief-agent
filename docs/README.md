# Documentation

This documentation follows the [Diátaxis](https://diataxis.fr/) framework: four quadrants split by whether you are studying or working, and whether you need practical steps or theoretical understanding.

| Quadrant | Purpose | Contents |
|----------|---------|----------|
| [Tutorials](tutorials/README.md) | Learning by doing | Stub until the code exists |
| [How-to guides](how-to/set-up-google-oauth.md) | Getting a task done | Google OAuth setup |
| [Reference](reference/cli.md) | Looking things up | CLI surface, classification tiers |
| [Explanation](explanation/architecture.md) | Understanding why | Architecture, design decisions, eval strategy |

## Status

The project is in the design phase. The v1 design is settled and recorded here; implementation has not started. Documents that describe behavior of not-yet-written code say so explicitly and describe the target state.
